## Prompt

Use case: ads-marketing. Create a polished landscape 16:9 GitHub README cover image for the native macOS app Macfold, release 1.0.
Input image 1 is the existing app icon, a cobalt rounded square with a pearlescent glass ribbon folded in an S curve. Preserve this recognizable icon design. This is a new cover composition, not a new logo.
Design a crisp premium product campaign: soft warm-white seamless background, immaculate typography, carefully staged silver aluminum laptop in three-quarter view occupying the right 60%, its rigid screen opened approximately 75 degrees, keyboard and hinge beautifully detailed. The laptop has one normal flat rigid screen, NOT physically curved or bent. Its display is filled edge to edge with an original rich cobalt-and-ice-blue flowing folded-glass wallpaper visually echoing the icon. Sharp, sculptural contours and luminous glass, not a blurred screenshot. A restrained sculptural glass ribbon behind the laptop subtly echoes the app mark without hiding the hardware. Grounded soft studio shadow; bright, airy, understated, precise materials.
On the left 36% use generous white space with the supplied app icon small above the wordmark. Exact headline text "Macfold" in very large dark navy modern sans-serif with impeccable kerning. Exact supporting text on two short lines: "Close the lid." and "Let the desktop follow." A small understated "1.0" below. No other text. Keep all text and key hardware safely within 6% margins. No badges, feature grids, buttons, website chrome, watermarks or Apple logos. Strong clear hierarchy at GitHub README width. The overall image must look like a finished, sharp, intentional product cover, not a blurry UI preview.
